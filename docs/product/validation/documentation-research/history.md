## Earlier evidence, before the 0.14 series

The existing [token-economics note](../../../plans/codeclew-token-economics-research.md)
records an early v0.2.5 qualification: 533,589 noncached input tokens for Clew
versus 171,685 for Default across five task classes (3.108x). A narrower navigation
case was 41,076 versus 46,550 (11.8% less). Different task distributions and token
definitions prevent pooling these into one universal saving.

The September [source-value first stage](../source-documentation-value-first-stage.md)
compared five fixture questions with native tools, released Clew 0.7.1 and a
manually supplied oracle source package. All five answers passed in each arm;
logical tokens, **including cached input**, were 279,095 / 715,286 / 87,704.
Model rounds were 16 / 24 / 5. Oracle source was charged in input. This demonstrated
feasibility of a sufficient package, not an automatic product saving. It did not
qualify a general planner or independent population-level quality advantage.

The subsequent [projection result](../source-documentation-projection-results.json)
used `gpt-6-astra`, High, one repetition and implementation
`a74ba0d880a03a4ef6aae7904421d3b16244e26a`: raw 490,717 versus compact 468,532
logical tokens, 4.52% less, with 5/5 answers and 19 obligations accepted in each
arm. It was a small paired format result. The [qualification](../source-documentation-qualification.md)
also preserved the automatic-preloading regression and deferred broad planning.
These historical model IDs describe executed studies, not current model routing.

The October 16 Weather calibration (`weather-value-trial-20261016`) reported
Clew/native ratios of 3.577x total tokens and 1.995x primary elapsed time at the
then-defined scope. Harness failures separately consumed 522,141 logical tokens;
they were not successful product work. Warm/compact/citation reruns and engine
controls on October 17 investigated projection, reuse and guarantees. Their
protocols, acceptance cases and accounting are distinct records in the inventory;
an accepted bounded control does not erase the calibration's economic result.

Reader and authoring studies from October 10-26 cover overviews/glossaries,
process ordering and collapsible branches, source links, human/technical metadata

and preserving 69. Its author-start-to-final-build time was 581.478 seconds;
this is not a complete same-task net-token advantage measurement. Public-reader

A model-page authoring pilot also exhausted an explicit 24-call allowance while
unresolved errors and an unstarted page remained. The user declined further
authoring. This is a budget-stopped/incomplete pilot, not evidence that every
requested model page was delivered or approved. The inventory preserves the
