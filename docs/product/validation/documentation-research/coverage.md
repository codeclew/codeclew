Metadata indexing is not a complete semantic rereview of every report. Narrative
records synthesize the major architecture, reader, source/provenance, authoring,
review, comparative-cost and failed-transfer families. Exact original source,
runtime/helper/model identities and timings are preserved when available; absence
means **unavailable**, not a reconstructed value or success. Reported interim
ADMITTED/RUNNING states can coexist with later terminal records. Prefer the
terminal accounting/outcome for that same experiment; a protocol is not execution.

Every report row labels its content as selected compact facts or **locator only**.
An empty facts object plus role/hash is a locator, not retained research content.
Important safe proposal/rejection findings are stated explicitly in
[mechanisms.md](mechanisms.md); a generic family description is not a recovered
experiment result.

Some model/critic phase details occur only in local receipts. No raw prompt or
session was opened to invent missing timings, costs or identities. The inventory
exposes selected aggregates and fingerprints, not dead local absolute links.
Authorized local custodians can locate a report by experiment ID/fingerprint.
Its absence from the public repository does not make uninspectable private detail
public evidence.
