# Semantic Context Pack: зачётный прогон на `pim-migrator`

Дата: 2026-08-01

## Решение

`clew agent-context` заменяет серию отдельных `resolve`, `context`, `cfg`,
поисковых и файловых запросов одним ограниченным пакетом. Команда за один
жизненный цикл worker:

- строит дешёвый syntax/declaration catalog;
- находит функции, классы, properties и file aliases по нескольким `--term`;
- запускает K2 только для выбранных функций и возвращает body anchors;
- добавляет типовые зависимости, например `AdaptiveBatchSettings` и
  `MigrationJob`;
- показывает дедуплицированные исходники, file headers, ссылки и близкие тесты;
- ограничивает canonical JSON в stdout через `--max-bytes`;
- пишет полный индекс, resolutions и контекст в отдельный evidence JSON.

Thread IR остаётся внутренним доказательством. Агент получает не граф целиком,
а проекцию, достаточную для конкретного изменения.

## Итерация по неудаче

Первая разведочная серия уже уложилась в 7,7–8,6 с и примерно 8,3 КБ stdout,
но потребовала 14–20 tool calls. Пакет показывал целевые функции и `main`, но не
заголовок `Main.kt` и не конструктор `MigrationJob`. Агенты повторно читали
файлы, исправляли позицию imports и уточняли test fixture.

После этого добавлены `fileHeaders` и semantic type-dependencies, а компактный
anchor в stdout сокращён до `anchorId`, файла, диапазона и syntax kind. Полные
anchor preconditions остались в evidence. Итоговый payload сохранил все нужные
исходники и тестовый пример в 11 312 байтах.

## Методика зачётной серии

Пять независимых `gpt-5.6-terra` с effort `medium` получили один baseline
`be34782d0e6045e0e1427c712fff4fdd1f11f62e` в пяти отдельных Git worktree.
Каждый агент использовал ровно один `agent-context` для навигации, менял два
файла, запускал targeted `cleanTest` и создавал один commit.

Время считается от первого зарегистрированного tool call до первого
`apply_patch` и до `git commit`. Token usage взят из последнего накопительного
`token_count` каждого rollout. Некэшированные tokens вычислены как
`input - cached input + output`. Лимит stdout относится к навигационному JSON
`agent-context`; обязательная загрузка общей policy skill в него не входит.

В худшем из пяти новых прогонов все зафиксированные критерии также выполнены:
не более четырёх команд до edit, один `agent-context`, stdout не более 12 КБ,
cold tool не более 10 с, edit не позднее 45 с, commit не позднее 120 с, не
более 12 tool calls, noncached не более 40 000 и raw total не более 400 000.

`rg` по-прежнему быстрее как операция literal byte search: локальный поиск
занимает менее 0,01 с против примерно 7,6 с у cold semantic pack. Победа
достигается на уровне всей агентской работы: один более информативный turn
устраняет повторные поиски, чтения и накопление большого cached context.

`benchmarks/reports/agent-context-pim-migrator.json`.
