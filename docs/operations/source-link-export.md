# Historical document exports

The native document generators and replay exporters have been removed. Existing
exports remain readable and retain their original provenance. Keep their entire
object closure and original evidence; do not overwrite them or recapture source
as a migration shortcut.

For new or updated documentation, author originals from saved Work and follow
the [checked human-page pipeline](../../skills/codeclew/references/compose-original.md).
Use the packaged renderer, local Sources and explicit repository mapping.
