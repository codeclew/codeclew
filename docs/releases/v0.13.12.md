# Codeclew v0.13.12 — retained reads and clearer readers

## Read retained changes without repeated catalog work

`change source`, `change render` and `change check-freshness` keep one store
alive through loading the comparison and reading its retained evidence.
They no longer admit the same catalog twice in a single request.

Catalog recovery validates each journal record and batches adjacent pack
removals before rebuilding the object-location map. It rebuilds before the
next addition or completion, preserves duplicate-object fallback, and holds
its shared write lock through replay and error cleanup. Invalid manifests,
chains and digest collisions still fail closed. This removes repeated work;
latency depends on the retained catalog and host.

## Keep report selection and source consistent

Filtering declarations updates the detail panel to the selected result.
No-match clears the previous source instead of showing a stale declaration.
Declaration and relation labels retain compilation identity, so main and test
observations with the same name remain distinguishable.
Enter and Space activate graph selections and reveal their details on narrow
screens. The graph scrolls inside its panel without stretching the page.

## Explain documentation History

History lists explicit released snapshots. Its heading and empty state now
explain that local proposal snapshots remain retained without becoming release
checkpoints. `clew docs render --root ROOT --publish` creates a checkpoint from
saved documentation; it does not recapture source or approve narrative meaning.

Invalid run-ledger diagnostics identify the logical run, rejected transition
and sequence without exposing a host path. Rejection does not repair or discard
the retained state.

## Reject source changes during bootstrap

The source launcher verifies the staged input closure again before saving its
reuse checkpoint. An edit, addition, deletion or mode change during a build
cannot bind current source metadata to an older runtime. The changed source and
previous checkpoint are preserved; the command rejects the raced publication.

## Public examples and scope

The public site follows three practical tasks: find a declaration, create one
source-linked document, and review saved edits. Recorded examples use official
0.13.11, retain its exact source revision and distinguish native output from
derived observations. The documentation update exercise is explicitly local,
separate from released Codeclew source. Meaning remains `UNASSESSED` and runtime
behavior remains unproven where the evidence has not established them.

C# reading and analysis through Roslyn, including supported ASP.NET Core MVC
attribute routes, remains included. Use a .NET 10+ host SDK and caller-restored
project inputs. C# writes, F#, Visual Basic and general framework coverage are
outside this profile. See [0.13.11 scope](v0.13.11.md).

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.13.12 sh
```
