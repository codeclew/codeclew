# Codeclew v0.13.17 — reuse approved answers and update retained sources

Find an existing approved method answer with `clew docs work find-answer` before
starting a new author/reviewer run. Lookup matches the normalized request and
subject against retained approvals and a selected Check. It preserves the
original approval and reports applicability to that current Check separately.
Ambiguous matches require explicit selection. The initial supported scope is
native method authoring 1.6 without actual role expansion, repair, external
context or protected notes; unsupported scope stays explicit. Lookup does not
call a model or recapture source. Follow the
[practical documentation workflow](../operations/field-documentation.md).

Incremental syntax capture can reuse successful extraction for an unchanged
file when service, path, bytes, language/dialect and bundled producer all match.
It rebuilds current revision, snapshot and source links while retaining scope
and budget checks. Changed files and parse-error trees are parsed again; compiler
results are not cached by this feature. A bounded 24-file Kotlin worker comparison
measured a 21.863% reduction in incremental capture plus Check assembly, with
complete evidence equality. Initial cache creation has additional cost. This
is a corpus-specific result, not an end-to-end documentation speedup; see the
[measurement and limits](../plans/question-results-and-incremental-evidence.md#measured-syntax-file-reuse-candidate-2026-10-06).

Compatible author/reviewer drivers can opt into typed model identities with
`modelRepresentation: "codeclew-model-ids/1.1"`. The host validates complete native
presentation, then removes duplicate raw delivery copies only from model input.
Canonical archives, evidence, receipts, citations and independent review delivery
remain intact. The host retains input before dispatch and parsed output before
decoding, preserving stable expansion aliases and recovery without repeat
dispatch. Existing canonical drivers and frozen mode 1.0 keep their original
format and behavior.

The complete four-call generated Java fixture used 36.2065% fewer paired
reference prompt-plus-schema text tokens, including protocol (expanded calls
alone: 38.8299%). The initial author call without duplication grew by 18
reference tokens. The
earlier two-real-first-call mode 1.0 ID measurement was 4.9184%. These are
bounded reference text counts, not provider billing or quality claims. Complete
carrier bytes still count for conservative host admission/reservation. See the
[compatible serializer API and example](../operations/model-id-serializer.md)
and [complete compact-delivery comparison](../plans/question-results-and-incremental-evidence.md#compact-role-evidence-representation-candidate-2026-10-06).

Linux builds now exclude macOS-only documentation test helpers. The failed
0.13.16 tag remains preserved without release assets; 0.13.17 contains its
intended product capabilities and the test-build fix.

Kotlin/Gradle metadata requests explicitly disable configuration-cache reuse
for the injected model task, so projects can keep their configuration-cache
setting enabled. Known build failures retain category-specific next actions
for repository access, TLS, dependencies, JDK/toolchain, compilation selection,
model extraction and launcher failures. Guidance is generated from a fixed
allowlist; private worker details remain private. The bounded regression
covers a configuration-cache-enabled synthetic Gradle project, not every
composite build or a qualification of a reported project/version combination.

Existing language capabilities remain included, including the C# Roslyn
[read-only scope introduced in 0.13.11](v0.13.11.md). C# requires .NET SDK 10+
and restored project inputs.

This remains a public pilot for macOS Apple Silicon/Intel and Linux x86_64,
including Windows through WSL2. Linux requires glibc 2.35+ and Python 3.11+.
The installer verifies checksums and never compiles Codeclew on the user's machine.

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.13.17 sh
```
