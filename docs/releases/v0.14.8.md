# Codeclew 0.14.8 — connected human documentation and local sources

Ordinary full-documentation requests use the bundled human-page workflow.
Each evidenced HTTP method/path gets its own page, starting at the exact handler
and leading through its thread and authored sequence. Shared service branches,
local helpers, external participants, normal returns, conditions and failures
remain distinct. Compact diagrams link participants and messages to their local
explanations; narrow screens retain a complete ordered reading trace. Local notes
stay in their participant's column and self calls use closed lifeline loops.

The default packaged workflow finalizes a guide with `--source-footers`: one bind,
mechanical local source materialization, rendering and checked export. Each page
ends with grouped file rows and clickable ranges separated by semicolons. Exact
cited excerpts sit behind one collapsed Code fragments disclosure. Existing
supported source views/unions can supply the original UTF-8 slices without new
source queries or capture. Missing Git URLs do not become invented links.
Source maps and authored Markdown remain authoritative and unchanged.

Retained proof candidate lookup now uses a per-validation identity multimap.
It preserves duplicate candidates, ambiguity checks, digests and receipt
verification while avoiding repeated full-packet scans. No persisted proof cache
or weaker freshness/validation policy is introduced.

`clew upgrade` activates the version-matched bundled skill for unchanged recorded
copies. Standard personal 0.14.7 copies can migrate on an exact official-content
match with a verified previous installed bundle in the same prefix. Custom,
modified, unknown and pinned copies are preserved. Explicitly installed project
destinations are recorded for future refreshes; other repositories and AGENTS
files are not scanned or rewritten. Fresh isolated prefixes do not refresh global
skills. Use `clew skill install` for initial setup, and `--pin` to opt a copy out
of automatic refresh. Reload the skill or start a new agent task after upgrading;
already loaded model instructions cannot be replaced by the installer.

Supported public packages remain macOS Apple Silicon, macOS Intel and Linux
x86_64 (including WSL2). Mechanical export checks establish exact bindings and
links, not global semantic completeness or observed production runtime behavior.
