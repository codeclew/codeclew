# Codeclew 0.15.16

Configure `gradle.prepareTasks` in the bound checkout's `codeclew.yaml` when
a Gradle generator needs to run before compiler capture. Codeclew runs the
tasks in an isolated checkout with the selected build inputs. The Check
lists declared outputs, their file digests, and which files entered the
selected Java or Kotlin compilation.

For one locally bound Kotlin/JVM Gradle service, run
`clew docs check --working-tree --root DOCS_ROOT --service SERVICE_ID`
to include saved local edits. Codeclew preserves the caller's checkout and
Git index. The Check records the base commit and a separate source snapshot
digest. Citations use the retained bytes and omit Git browser links for the
working-tree capture.

Default support reports can include fixed preparation failure codes, such as
a missing task or a dependency on the compiler task. Task names, filesystem
paths, and Gradle property values stay out of these reports.

See the [Gradle capture guide](https://github.com/codeclew/codeclew/blob/v0.15.16/docs/operations/gradle-project-properties.md)
and the [installation guide](https://codeclew.github.io/codeclew/). Existing
installations can update with `clew upgrade`.
