# Codeclew v0.13.15 — selected retained evidence reads

Retained `clew docs context --service SERVICE --snapshot SNAPSHOT --dependency ID`
now resolves the selected evidence closure before loading unrelated observation
payloads. It validates the complete dependency membership inventory and required
selected payloads, preserving source text, citations, provenance, boundaries,
compilation scope and snapshot/selector cursor binding.

The response includes `evidenceValidation` with
`SELECTED_DEPENDENCY_CLOSURE` and `exhaustiveIntegrityAudit: false`. Unread capture
observations, contracts and unrelated payloads have not undergone an exhaustive
integrity audit. Missing or corrupt required evidence fails explicitly. Source
objects and source-input contracts still load in full; other selectors and
`--refresh` retain their existing full reads. Validation metadata participates in
the stdout budget, so continue with returned cursors rather than assuming old
page boundaries.

The accepted local saved-method comparison preserved all 75 items across two
pages. Successful object fetches per page decreased from 1,996 to 105; fetched
bytes decreased from 5,142,771 to 2,648,886. These counts include repeated fetches
and do not measure physical disk IO. Warm debug timings are not an installed
release or end-to-end model speedup. See the [implementation and limits](../plans/question-results-and-incremental-evidence.md#first-scoped-read-candidate-2026-10-06).

Short model IDs remain a separately scoped improvement, not a shipped feature.
Their reference-token feasibility measurements do not establish provider usage
or answer quality. Existing language capabilities remain included, including
C# Roslyn analysis with a .NET 10+ host SDK and restored project inputs, under
the [read-only scope introduced in 0.13.11](v0.13.11.md).

This remains a public pilot for macOS Apple Silicon/Intel and Linux x86_64,
including Windows through WSL2. Linux requires glibc 2.35+ and Python 3.11+.
The installer verifies checksums and never compiles Codeclew on the user's machine.

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.13.15 sh
```
