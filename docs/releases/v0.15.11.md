# Codeclew 0.15.11

Codeclew can link a retained external call to the exact service in a
shared catalog when the evidence identifies that service. Ambiguous
identities stay unresolved.

Kotlin/JVM capture prepares Java source generators attached only to the
selected Java compile task. It uses their outputs without running the
selected Kotlin or Java compiler task, or unrelated prerequisites.

Kotlin/JVM capture now qualifies the native kapt inputs for Kotlin Gradle
Plugin 2.2.21 on its supported Gradle and JDK 21 configuration. It
retains generated Java and Kotlin sources and project class directories
as compilation inputs. See the
[Kotlin qualification guide](../operations/kotlin-qualification.md)
for the exact supported configuration.

Codeclew remains a public pilot. Upgrade with `clew upgrade`.
