# Codeclew v0.13.26 — bounded dependency reads and source-only Kotlin projections

`docs work read-dependency-part` recovers oversized immutable `DEPENDENCY` records as bounded UTF-8 JSON parts, with exact Work, snapshot, and digest receipts. See the [documentation-agent recovery guide](../operations/documentation-agent-recovery.md) for exact references and bounded recovery.

Completing manual reads supplies initial-context omissions; automatic author and reviewer packet gates remain independent. Helpers remain in the source inventory without requiring standalone narratives, and internal process candidates appear only when `showInternalProcesses` is enabled.

Kotlin analysis adds a controller-bound, source-only direct-interface projection for a non-generic direct captured interface and an unannotated overriding method; direct mappings are handled separately. It requires parse-valid controller and interface files inside configured committed source roots, preserves both source references, and matches the configured prefix and declared parameter signature. Results report `SYNTAX` coverage and mark override signatures `SOURCE_OVERRIDE_SIGNATURE_NOT_COMPILER_VERIFIED`. HTTP mapping declarations alone do not establish server startup. Incomplete, ambiguous, transitive, generic, nullable-mismatch, and parse-error cases remain explicit unresolved evidence; runtime registration stays conditional.

This scope does not establish runtime routing, delivery, transaction commit, or acceptance of the unavailable private full checkout.

v0.13.26 adds opt-in offline diagnostics with `clew support collect --root /path/to/docs-root --include-cache --work 'PASTE_64_HEX_WORK_ID' --output /path/to/new-bundle`; without `--include-cache`, collection remains metadata-only. `--work` selects the saved Work's immutable snapshot. The private bundle includes docs-local SQLite/raw WAL, receipts, latest job and selected checkpoints, frozen invocation job-inputs, job-results, job-model-inputs, and job-model-wire-results JSON, fixed-role model-ID-map JSON, known Work/run draft JSON directories, and selected proposal JSON; inline review stays in the saved job. Paths derive from validated IDs; persisted `outputDirectory` is never followed. It records hashes, uses 0700 directories and 0600 files, and leaves original source unchanged. Git history, source bindings, global `CODECLEW_HOME`, and automatic upload are excluded. Cached source fragments/private records may be copied unsanitized. `COPIED_NOT_HYDRATED` does not verify full semantic/cache-object closure. The expanded six-test suite passed in 75.62s; offline replay verified exact saved input/result/checkpoint/draft bytes and refused a `.git` outputDirectory.
