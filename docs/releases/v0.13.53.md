# Codeclew 0.13.53 — protected pages and consistent Markdown

Service-profile cards and secondary narrative details render Markdown tables,
code and links with the shared safe renderer. MDX preserves canonical link
destinations, while literal source evidence stays unchanged. Return links
distinguish a whole process from an exact process step and preserve its context.

Human-owned Markdown pages have stable standalone HTML and MDX routes, an exact
original download and retained source bindings with explicit file, revision,
range and digest. Their separate assessment does not rewrite the original.
Binding comparisons remain distinct from meaning review; an unchanged citation
does not establish every claim in arbitrary prose. Protected HTML pages include
the shared reader header and styles.

Public pilot for macOS Apple Silicon/Intel and Linux x86_64, including Windows
through WSL2. Linux requires glibc 2.35+ and Python 3.11+. On Windows, keep the
installation, state and repositories in the WSL2 Linux filesystem.

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | sh
```

The installer verifies published SHA-256 checksums and never compiles Codeclew.
The core package includes Kotlin 2.4.10 and C# Roslyn. Conditional Rust/Python
mutation remains a public pilot with PARTIAL/UNSURE evidence, native validation
and explicit obligation acknowledgement. Apple code signing and notarization,
native Windows, Linux ARM64 and musl distribution remain outside this release.
