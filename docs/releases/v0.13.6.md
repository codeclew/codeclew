# Codeclew v0.13.6 — selected context and linked source calls

## Move an explanation to explicitly selected source context

A manual retained-paragraph proposal can select current source context without
rewriting the paragraph. The `explanationContext` instruction requires the complete
retained operation and current source/dependency evidence, exact event anchors,
and matching paragraph and context digests. Changed baselines, incomplete evidence
and forged migration metadata are rejected.
The first migration route preserves exact logical source/dependency sets and
requires compatible associations, providers and compiler scope. Stale
source-derived fields must be regenerated before selecting their current context.

The paragraph keeps its text, identity and declared author. A separate context
editor, instruction digest, previous snapshot and previous context digest record
the selection. Context review remains `UNASSESSED`; selected source does not verify
the explanation's meaning. Later text edits retain the selected context, and a
later source change can make it stale. Old publications and offline exports keep
their original bytes and source pins.

Ordinary readers and explicit native authored-paragraph exports display text
authorship, context selection and freshness separately. Native source appendices
link each paragraph to its own frozen selected or original source context.

## Follow exact retained calls between documented processes

Native page selections can opt into `expandSourceCalls`. Exact compiler call
occurrences link parent pages to a uniquely selected child endpoint page in the
same service and compiler scope,
and worker calls link to retained helper bodies in `source-calls.html` and MDX.
Repeated calls retain distinct arguments, conditions and occurrence identities.
Incoming links show both documented parents when they share a selected child.

Expansion is bounded to depth two, 64 additional bodies and 1 MiB of additional
source text. Cycles, missing bodies, ambiguous targets, compilation-scope mismatches
and dependency boundaries remain explicit frontiers. Source calls do not establish
runtime dispatch, queue scheduling, delivery or receiver identity. Omitting the
flag or setting it to false preserves ordinary output bytes.

Pages also expose a separate `examinedSourceDigest` and reverse examined-process
membership. A child helper change identifies both examining parents for review;
a local parent guard change stays local, and retargeting removes the old child
membership when no other examined path retains it. Provenance-only coordinate
relocation with unchanged retained text and unrelated global revisions do not
change this local digest. Existing whole-bundle and file hashes retain their contracts.
These links identify review candidates within examined source, not runtime impact
or whole-program change safety.

## Keep reader evidence links at the cited source range

Operation readers distinguish a containing-class citation from an exact callable
excerpt. Constructor claims stay attached to the class source; a nested method
excerpt does not acquire those claims merely because it shares the same source
record. The source-local diagram still links to the selected method body.
Long uncertainty codes and plain declaration identities wrap on narrow screens;
retained source text keeps its own horizontal scroll area.

## Scope

This release combines explicit maintained-context selection with bounded native
source navigation. The runnable owned Java fixture and regression sources are
included in the repository. Automatic retained-edit role delivery, a public model
transport qualified for reuse, formal draft meaning review, live Q&A, corporate
capture, large-scale admission and engineering-user qualification remain separate
work. Existing configured model-driver interfaces retain their contracts.

See the [context-selection guide](../operations/docs-snapshot-store.md#explicitly-select-a-new-paragraph-source-context)
and [native-pages guide](../guides/native-static-pages.md#opt-in-linked-source-call-context)
for evidence requirements and commands. Install the pinned version after its
assets are published:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.13.6 sh
```
