# Codeclew 0.7.0 — analysis modules and clearer service documentation

Java and Kotlin now emit portable annotation facts for a shared Rust Spring
interpreter. HTTP mappings, Kafka listeners and schedules use one policy,
including aliases, defaults, repeatable annotations and inherited bean context.
`clew capabilities` lists installed modules with their schemas and compiler/JVM
requirements. Framework derivation keeps its own policy, implementation and
input provenance. No Kotlin 1.9 engine or dynamic plugin loader is added.

Kotlin workers use JDK 21 independently of the project's build JDK. Set
`CODECLEW_WORKER_JAVA_HOME` to choose the analyzer runtime while keeping
`JAVA_HOME` for Maven/Gradle. Maven reports its actual build JVM; Gradle retains
its selected toolchain. Wrong worker JDKs and unresolvable Maven runtimes return
actionable errors. Project-model cache identity tracks these JDKs separately.

Unknown cross-engine compiler options now report the option names, project and
analyzer compiler versions, and the qualification restriction. Private option
values are omitted. For Kotlin 1.9, the exact option
`-Xannotation-default-target=param-property` is explicitly ignored during
analysis and recorded as a normalization boundary. Native project arguments
remain unchanged.

Generated documentation replaces long sequences of opaque step links with one
supporting-code action per paragraph and suppresses repeated prose in HTML and
Markdown. The authoring skill now requires concrete outcome rules and traces
calculated values through the actual query, mapper and constructor. It includes
an independent reader workflow for requested comprehension reviews.

Validation includes live compiler Spring fixtures for Kotlin 2.1/2.3/2.4 and
Java 17/21, a Kotlin 1.9 Maven fixture with a Java 17 project JVM and JDK 21
worker, compiler-option/coverage regressions, and project-model cache checks.
The complete local CI gate passed. A fresh independent reader accepted the
revised five-service, three-scenario documentation sample with no blocking
findings. This is bounded comprehension evidence; browser layout and deployed
behavior remain unverified. Details are recorded in the implementation plan.

Install and refresh the portable skill:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.7.0 sh
clew skill install --agent codex
```

The default package includes Kotlin 2.4.10. The optional Kotlin 2.3.0 pack remains
available through `clew pack install kotlin23`. Project and operation admission
still determine supported actions; module registration does not expand mutation
qualification.
