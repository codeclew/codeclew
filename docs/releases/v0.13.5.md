# Codeclew v0.13.5 — maintained explanations and captured instructions

## Edit a retained explanation without losing its context

The manual Work/proposal path can read a large retained operation in bounded,
resumable parts and edit its title or one exact explanation paragraph. The full
retained record remains pinned to the Work, snapshot and content digest; SOURCE
parts retain their separate contract. Unsupported oversized kinds still block
completion instead of disappearing from the evidence.

A paragraph edit records its declared author and USER_DOCUMENTATION provenance.
It changes the selected text and attribution while preserving unrelated operation
fields, event links and source/dependency IDs. Publication requires the existing
manual `--unassessed` route. Originally linked code remains unverified context;
it does not verify the meaning of the new prose. HTML and Markdown display that
attribution and status.

Concurrent baseline changes, stale expected text and conflicting replacements
are rejected. Publication refuses to rebind the edited paragraph to different
source bytes. Later source regeneration preserves protected authored content and
its original linked context, or reports a conflict; old publications remain
unchanged. Automatic author/reviewer paths continue rejecting retained edits
until actual role delivery is supported.

## Include captured operational instructions in native pages

`docs pages render` can explicitly include captured protected note IDs for the
selected service or one of its supported sections. The overview displays the
original text and declared author separately from source-derived conclusions;
its other views link to the instructions. The projection and manifest retain
note, association and version identities. Included content is escaped as inert
text in both HTML and MDX.

The exporter resolves notes from the exact saved Check snapshot. Source changes
can update code conclusions while preserving the instruction; changing or
removing a live association does not rewrite old bundles or their offline exports.
These standalone exports do not create ordinary documentation history entries.
Entity/scenario/view note targets need a later typed expansion.

## Scope

This increment reuses retained Work, proposal, publication, protected-note and
snapshot mechanisms. It does not add a public manual meaning-review route,
automatic retained-edit role delivery, a model connection or live Q&A. Actual
corporate capture, clean-host qualification beyond the tested platform and human
usability evaluation remain separately unqualified.

See the retained-part and native-pages guides in this release for exact commands.
Install the pinned version after its assets are published:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.13.5 sh
```
