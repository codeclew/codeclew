# Codeclew 0.15.18

Saved-source Kotlin Checks can retain exact compiler evidence when a selected
classpath entry is an absent directory declared by a completed Gradle producer.
This covers source generators that leave their separate classes output empty,
including the verified KSP and Konvert configuration.

Codeclew records the directory's producer and position in the selected
classpath, checks the effective compiler arguments, and verifies the input again
after successful compilation. Missing archives, unproven outputs and changed
inputs still cause a receipt failure.
