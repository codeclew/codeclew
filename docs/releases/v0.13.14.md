# Codeclew v0.13.14 — accurate service documentation labels

Service readers now say **SERVICE**, or the localized equivalent in the Russian interface,
instead of calling every service documentation container a microservice.
The generic container does not establish that architecture. Interaction
scenarios keep their existing label, and the reader continues to show source
freshness, review status and runtime evidence separately.

Previously published documentation snapshots remain immutable. Refresh a
reader from its saved snapshot with `clew docs render --root ROOT --publish`;
this creates a new checkpoint without recapturing source or approving narrative
meaning. Existing snapshots and caller notes remain retained.

The retained-read performance, selection, compilation identity, History and
bootstrap fixes from [0.13.13](https://github.com/codeclew/codeclew/releases/tag/v0.13.13) remain included.
C# analysis through Roslyn remains available with a .NET 10+ host SDK and
caller-restored project inputs. Its read-only profile and supported ASP.NET
Core MVC attribute routes retain the [0.13.11 scope](https://github.com/codeclew/codeclew/blob/v0.13.11/docs/releases/v0.13.11.md).

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.13.14 sh
```
