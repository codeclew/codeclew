# Codeclew 0.14.2 — service-oriented reader navigation

The optional portable Markdown reader accepts explicit navigation JSON for one
or more services. Readers can find each service's overview, locally triggered
processes, domain data and participation in shared routes. HTTP, Kafka, scheduled
and background starts have distinct labels; a shared route's origin is separate
from a participant's local entry. Service hubs expose existing section links,
and route pages link to participants and back to their route sections.

Breadcrumbs identify the current page and linked section. Native disclosures,
ordinary links, keyboard focus and the narrow-screen menu keep navigation usable
offline. Page/anchor references and ownership are validated before rendering;
invalid explicit metadata refuses instead of silently dropping destinations.
Existing callers without navigation metadata retain the flat menu. The neutral
comparison output is preserved.

The navigation file is an authored reader index. It does not infer a graph,
delivery, ordering or service ownership from filenames or shared topics, and
adds no source capture, planner, author model or evidence-binding engine. Short
labels describe already documented sections. The skill explains how to maintain
this index as pages change.

Data-field guidance also preserves exact source/code identifiers and casing in
the Field column, with translations and business meaning in the explanation.
Aliases of one conceptual value stay together; unavailable identifiers are not
invented. Checked source bindings and retained components continue through the
existing compose/export workflow. These bounded reader improvements do not
establish semantic completeness or additional compiler/runtime coverage.

The distribution remains a public pilot for macOS Apple Silicon/Intel and Linux
x86_64, including Windows through WSL2. Linux requires glibc 2.35+ and Python
3.11+. Keep WSL2 installation, state and repositories in the Linux filesystem.
The installer verifies SHA-256 checksums and never compiles Codeclew locally.
Code signing, notarization and general-availability guarantees are not claimed.

Install or upgrade:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | sh
```
