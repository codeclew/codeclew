# Codeclew 0.15.19

Set `"evidenceMode": "PREPARED_FACTS"` in an installed documentation runner job
to include compact, cited propositions from supported retained source. The
default, `RETAINED_SOURCE`, uses the ordinary source workflow. The runner records
coverage gaps and continues with retained source when a projector or proof is
unavailable.

Java projection uses JDK 21 or later. C# projection uses .NET SDK 10 or later and
requires the exact captured compilation unit. For TypeScript, install the
companion locked dependencies outside the installed skill and put that
directory's `node_modules` on `NODE_PATH` for preparation. TypeScript projection
is method-local. Java and Kotlin conclusions remain bounded by their admitted
source and call evidence. Cross-service behavior and runtime execution remain
open.

New committed Java and Python syntax captures can retain complete original
files. If an older syntax capture lacks a complete file required for discovery,
capture the same revision again with `clew docs check` and prepare Work from the
new snapshot. Earlier snapshots retain their original coverage.
