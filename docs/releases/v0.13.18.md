# Codeclew v0.13.18 — linked documentation from retained source

Select exact declarations from a saved Check and render offline HTML and MDX
with the same native reader for Java, Kotlin, C#, TypeScript and Rust. Pages
retain sources, citations, available compiler control flow and exact call
navigation. Rust retains syntax structure with unresolved call targets; C#
remains the read-only Roslyn preview. Unsupported evidence stays explicit.
See the [native retained-source guide](../guides/native-retained-source.md).

New Kotlin evidence from the 2.4.10 analyzer can explain guarded parameter/local
and ordinary backing-property definitions, call arguments and conditional
returns through the shared Java/Kotlin transfer engine. Named arguments retain
source order and compiler formal slots; omitted defaults and external call
results remain unavailable or symbolic. Constructor storage proof can establish
that a selected endpoint and worker receive the same source-declared queue
allocation. These facts establish neither runtime values nor submission,
scheduling, delivery or completion. Older saved Checks remain immutable.

Use `clew docs endpoint list`, `exclude` and `include` to control one exact
callable's publication in its service and compilation scope. Keep the original
page selection: reinclusion restores its pages and retained explanations.
The policy preserves captured analysis and immutable historical publications;
it is not redaction, and an excluded callable can remain an examined callee.
See the [publication selection guide](../operations/endpoint-publication-selection.md).

The core install records project compiler version separately from its 2.4.10
analyzer, including original language/API settings and the selected engine.
Kotlin 1.9 keeps its explicit analysis-language upgrade boundary. A single local installed core passed native Maven builds and offline
documentation checks for the public Pipeline fixture on Kotlin 1.9.25, 2.1.21,
2.3.0 and 2.4.10. A declared unsupported 2.99.0 compiler returned an explicit
`UNRESOLVED` diagnostic without successful service evidence. The
[bounded matrix and source limits](../guides/native-retained-source.md) preserve
partial coverage and byte/citation checks. Native compiler semantic equivalence
and broader mutation support are not implied.

Existing language and authoring capabilities remain included. C# requires .NET
SDK 10+ and restored project inputs. This remains a public pilot for macOS Apple
Silicon/Intel and Linux x86_64, including Windows through WSL2. Linux requires
glibc 2.35+ and Python 3.11+. The installer verifies published checksums and never
compiles Codeclew on the user's machine.

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.13.18 sh
```
