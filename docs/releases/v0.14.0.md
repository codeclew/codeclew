# Codeclew 0.14.0 — macOS and Linux public pilot

Documentation authors can work from retained source files, compact computation
views and reusable evidence, then compose and export pages with checked source
bindings. The portable skill includes these helpers and an optional renderer
example. Original source identity and provenance remain available separately
from the compact author view and human reader content.

Genuine Work SOURCE references and engine-validated native file citations survive
mixed-source page composition and checked export. The engine reloads native
evidence before admitting its bindings. These checks establish source identity
and integrity; they do not prove the truth of an author's explanation.

C# documentation retains compilation-unit source membership, including host
registration files that lack a conventional declaration. Nonempty files preserve
their original bytes; empty files keep explicit metadata without invented
bodies. Source-bound C# regions distinguish branches, handlers, loop exits and
normal continuations. Abrupt handlers no longer acquire false normal joins.
Unsupported interprocedural, finally and disposal semantics remain explicit.

Selected retained contract and schema declarations can become reader components
that survive composition and export. Composite keys have explicit groups and
member roles. Database-section selection requires a source-authenticated scope
and retains the complete original file. Unsupported SQL dependencies refuse
narrowing and require the full projection. Material partial-projection notices
remain visible; generic display metadata is reduced.

The retained Kotlin workflow preserves source-backed argument and default
metadata and exact whole-file query behavior. Compose annotation errors now
identify the page, fragment and missing fields without echoing source content.

These are bounded source-retention, structure, binding and presentation
improvements. They do not establish complete documentation, all-path runtime
behavior, automatic database ownership or SQL query execution semantics.
Research has not established uniformly complete prose or a general token-cost
advantage. Previous negative and incomplete outcomes remain valid.

The distribution remains a public pilot for macOS Apple Silicon/Intel and Linux
x86_64, including Windows through WSL2. Linux requires glibc 2.35+ and Python
3.11+. On WSL2, keep installation, state and repositories in the Linux filesystem.
The installer verifies SHA-256 checksums and never compiles Codeclew locally.
Code signing, notarization and general-availability guarantees are not claimed.

Install or upgrade using the public installer:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | sh
```
