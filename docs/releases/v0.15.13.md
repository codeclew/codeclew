# Codeclew 0.15.13

Failed Kotlin Gradle captures now retain a shareable compiler plugin diagnostic.
The first unavailable or failed native kapt check and the actual ABI rejection
are recorded separately. Run `clew support collect --root ROOT --snapshot SNAPSHOT
--output NEW_DIRECTORY` to inspect the saved facts offline. The report identifies
the original failure runtime separately from the collector. Earlier failures
report the diagnostic as unavailable.

Supported compiler plugin combinations and admission rules are unchanged.
