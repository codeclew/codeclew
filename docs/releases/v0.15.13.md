# Codeclew 0.15.13

Kotlin Gradle compiler capture now verifies a selected native compilation before
replaying qualified all-open options for compiler evidence.

- Kotlin 2.2.21 with Gradle 8.14.1 and JVM 21 supports Spring and kapt.
- Kotlin 2.4.10 with Gradle 9.4.1 and JVM 25 supports Spring, kapt, and selected
  Java source producers attached to `compileJava`.
- Kotlin 2.4.20 with Gradle 9.6.1 and JVM 21 supports explicit all-open
  annotation options without kapt.

The retained evidence identifies the native task, revision, compiler inputs,
and classfile comparison. Incompatible options on these paths remain
explicit capture boundaries.

Failed Kotlin Gradle captures now retain a shareable compiler plugin diagnostic.
The first unavailable or failed native kapt check and the actual ABI rejection
are recorded separately. Run `clew support collect --root ROOT --snapshot SNAPSHOT
--output NEW_DIRECTORY` to inspect the saved facts offline. The report identifies
the original failure runtime separately from the collector. Earlier failures
report the diagnostic as unavailable.
