Codeclew 0.13.39 adds structured field descriptions to domain-model readers.

Native HTML and portable MDX model pages include a static field table with each field path, its retained purpose, representation-specific types and requiredness/nullability. Different representations keep separate constraints; missing declarations remain explicit. On narrow screens, rows retain visible column labels without requiring horizontal scanning. Original descriptions, field anchors, complete mappings and source evidence remain available below the table.

A model plan can explicitly link a service entities section to its canonical field table through an existing service processLink. This navigation does not create a domain ownership declaration. The original service account and its ownership status remain separate.

Process Data Flow remains an opt-in view supplied by the data-model plan. Exporting a new release does not update an already deployed documentation bundle: the reference site must be regenerated with its accepted reading and data-model inputs. This correction retains those inputs and their source/provenance boundaries.

Each export uses one chosen language, English or Russian. Selecting it does not translate retained source or upgrade an editorial review. Static evidence is not application runtime proof.
