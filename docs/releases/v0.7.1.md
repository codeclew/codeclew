# Codeclew 0.7.1 — qualified Kotlin options and bounded Maven logs

Supported Kotlin projects can now retain `-Xjsr305=strict|warn|ignore` and
`-Xjvm-default=disable|all|all-compatibility` during analysis with Kotlin 2.4.10.
Qualification depends on the analyzer and option value, without another project
patch-version or JVM-target whitelist. Both admission and the worker check exact
values and reject conflicting modes.
The arguments are forwarded unchanged; projects do not need to remove them.
Special annotation rules remain outside this option qualification. Existing
project compatibility, language/API, JVM-target and plugin checks still apply.

The qualification samples real 1.9.0, 1.9.24, 1.9.25, 2.0.21 and 2.4.10 compilers
on JDK 21, with additional analyzer checks for JVM targets 1.8 and 21:
JSR-305 null diagnostics, inherited interface dispatch, default methods and
compatibility bridges. Compatible analysis still records its language/API 2.0
boundary and does not enable mutation or assert universal compiler equivalence.
See [the exact scope and compiler checks](https://github.com/codeclew/codeclew/blob/v0.7.1/docs/operations/kotlin-19-analysis-options.md).

Maven compilation and effective-POM stages now drain build logs with bounded
memory instead of treating their combined size as a model-output limit.
Successful builds with large or binary logs are accepted when the separate
model is valid. Stdout model extraction retains its 4 MiB limit. Native failures
report the actual stage, exit status or signal, and separate stdout/stderr byte
counts without printing private output. Recovery instructions reproduce the
compilation and reactor selection that Codeclew actually uses.

A public JDK 21 / Java release 17 fixture covers 5 MB stdout plus 6 MB stderr
and distinguishes a real compiler error from a model-output failure. These
regressions do not establish the cause of an unavailable private repository's
failure. See [Maven diagnostics and reproduction](https://github.com/codeclew/codeclew/blob/v0.7.1/docs/operations/maven-build-failure-diagnostics.md).

The complete local CI gate and the 6/6 Rust/Python RELEASE mutation pilot passed.
A public Maven fixture declaring Kotlin 1.9.23 with both options opened an
analysis context successfully through the CLI, retaining PARTIAL/UNSURE authority.
The real compiler checks cover 42 invocations with both options present. Private
application reproduction and native Windows execution are not claimed.

Install and refresh the portable skill:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.7.1 sh
clew skill install --agent codex
```

This remains a public pilot for macOS arm64/x86_64 and Linux x86_64, including
Windows through WSL2. The default package contains Kotlin 2.4.10; Kotlin 2.3.0
remains an optional read-only pack.
