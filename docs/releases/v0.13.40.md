Codeclew 0.13.40 adds an optional remote source rendering mode.

`docs render`, `docs pages render` and `docs dsl render` accept
`--source-mode embedded|remote`. Embedded source remains the default. Remote
exports use exact GitHub or GitLab repository links instead of automatically
attached source bodies, syntax snippets and source-outline diagrams. The same
policy applies to standalone HTML, portable Docusaurus data, source appendices,
comparison attachments and auxiliary original/download files.

Links retain each source's own commit SHA, repository, file and line range,
including historical evidence. Self-managed hosts, nested groups and independent
SSH/web ports use explicit `--source-map` bindings. Dirty, generated, missing or
ambiguous bindings fail explicitly. No provider request or remote availability
check is performed.

Authored explanations, intentional quotations, contract examples, source
identities and provenance remain. Export mode and mappings are recorded in the
manifest and bound into export identity. Local evidence and previous exports are
unchanged. Remote `docs render` exports an existing saved publication into the
required new output directory; local authoring, refresh and publication remain
explicit preceding steps.

See [source-link export](../operations/source-link-export.md) for commands,
mapping examples and sharing limits.
