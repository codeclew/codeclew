# Codeclew 0.14.1 — readable Markdown documentation

The optional portable Markdown renderer now uses Codeclew's existing colors,
typography and cat artwork. Page-title navigation marks the current page;
mobile navigation collapses and authored tables scroll locally with keyboard
focus. CSS and decorative artwork are embedded for offline reading, with a
local SVG favicon. The retained `--theme neutral` option preserves previous
comparison output. English and Russian reader labels are supported.

The author reference explains how to choose a proportional reader structure:
purpose and reading paths for overviews, conceptual values and aliases for data,
ordered work and consequential outcomes for processes, and clear request/result
boundaries for integrations. Detailed configuration can be disclosed separately;
key failures and commit/acknowledgement boundaries stay visible. Literal fragment
boundaries preserve paragraphs, adjacent table rows and retained components.

These instructions use the existing authoring and self-review workflow. They
add no model, critic stage, automatic prose conversion or semantic lint. Checked
composition/export still verifies source bindings and deterministic output,
not semantic truth or complete runtime coverage. The export checker admits only
the explicitly referenced, byte-checked local `favicon.svg` in addition to its
flat pages; other local assets and unsupported link forms remain restricted.

This corrective release includes the portable renderer and skill changes.
Existing source-analysis and runtime limitations remain unchanged.

The distribution remains a public pilot for macOS Apple Silicon/Intel and Linux
x86_64, including Windows through WSL2. Linux requires glibc 2.35+ and Python
3.11+. Keep WSL2 installation, state and repositories in the Linux filesystem.
The installer verifies SHA-256 checksums and never compiles Codeclew locally.
Code signing, notarization and general-availability guarantees are not claimed.

Install or upgrade:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | sh
```
