# Codeclew 0.13.54 — macOS and Linux public pilot

This release improves source-grounded documentation of processes, domain objects,
external configuration and data exchanged at service boundaries.

Domain readers lead with business names and meanings. Explicit representations,
source paths, uses and proposed relationships remain available in details. The
renderer does not infer canonical identity from matching code names or merge a
historical object with its current counterpart.

Unknown ownership does not hide retained business descriptions or explicitly
bound data objects. Visual navigation updates the primary heading, and directed
branch labels have separate space for their complete conditions.

Compiler capture also retains versioned YAML/properties files in standard selected
Java/Kotlin resource siblings from the admitted snapshot. Nonstandard resource
roots remain outside this bounded projection; no environment values or profile
precedence are resolved. Concurrent fresh-home initialization reopens and checks
a directory created by another process without following symlinks.

External profiles group operations by service and configuration binding. Authored
static references show whether their source matches the selected snapshot, has
changed or is unavailable. Reference names do not establish resolved values,
active profiles or runtime destinations.

Source-derived payload views reuse exact model-field representations and keep
requests, successful responses, errors and message components separate. Each view
states its coverage and specific missing definition. Nullable implementation
fields do not prove optional wire properties or a complete serialization schema.
Retained declared contracts remain separate from implementation mappings.
Repeated source citations across model fields and payloads share unique evidence
accounting while retaining per-reference validation and separate work bounds.

The portable skill includes bounded collection and evidence repair, explicit
canonical mappings, targeted handler/type lookups and a new generic semantic
reader example. Normal and debug checks require concrete reader answers; counts,
formatting and executable examples alone are not semantic approval.

The distribution remains a public pilot for macOS Apple Silicon/Intel and Linux
x86_64, including Windows through WSL2. Static evidence does not establish runtime
execution, message delivery or the factual correctness of arbitrary authored prose.
