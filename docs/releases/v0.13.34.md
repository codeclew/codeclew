Codeclew 0.13.34 fixes Kotlin compiler compatibility without changing project settings.

The Kotlin 2.4.10 analyzer accepts the qualified `-Xconsistent-data-class-copy-visibility` option for project compilers starting with Kotlin 2.0.20 and `-Xjvm-enable-preview` for supported project modes. Both flags retain their original spelling and order. Compiler-backed checks compare private data-class `copy` access, JVM 25 classfile versions and preview markers against Kotlin 2.3.21, verify preview execution on JDK 25, and retain compiler refusals for inaccessible calls. Other unqualified cross-engine options and unknown plugin ABIs still fail explicitly.

Gradle model extraction now reads the selected Kotlin compilation's effective JDK executable, including Kotlin task toolchain overrides, before the Java launcher fallback. A Gradle daemon or packaged analyzer running on JDK 21 can analyze a project targeting JVM 25 against its configured JDK 25 APIs. Resolving a configured Kotlin toolchain may fail; Codeclew does not substitute the build JVM in that case. JDK identity, compiler options and target remain part of the analysis cache identity.

JVM 25 target generation by itself was already supported by the packaged compiler. This fix corrects project-JDK discovery and option admission; it does not lower the project's target or disable either required flag. Compiler facts establish source semantics, not runtime execution of the application.

Ordinary K2 validation failures now retain bounded private compiler diagnostics and selected compilation context locally. A later `support collect --include-private-logs` can export the exact records referenced by a saved Check, without a prior live diagnostic wrapper. Collection validates record identities and digests, reports missing or evicted records, and does not follow arbitrary paths or include a Git snapshot. Metadata-only and cache-only collection do not export compiler records.

The JDK-provider defect above is reproducible and covered by tests. The cause of the separately reported production K2 validation failure remains unestablished; missing compiler details in older diagnostic archives cannot be reconstructed.
