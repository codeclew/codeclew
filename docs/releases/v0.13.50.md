# Codeclew 0.13.50 — Markdown and domain field tables

Authored reading bodies now render safe pipe Markdown tables in native HTML and
Docusaurus. Domain model pages present the original field, an explicit readable
name and the complete comment in three columns. Field disclosures retain their
source evidence, label provenance and representation details; canonical links
preserve field and process context. Catalogue type filters hydrate consistently
in Docusaurus.

Existing plans remain supported. Optional readable names are evidence-bound
authored interpretations; generic meaning titles do not become field names.
Historical descriptions, source records and review limits remain unchanged.

Install the public macOS Apple Silicon/Intel or Linux x86_64 pilot:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | sh
```

Windows users can install inside WSL2. Linux requires glibc 2.35+ and Python 3.11+.
The installer verifies the published SHA-256 checksum and does not compile locally.
For offline installation, download the installer, its checksum, the platform
archive and its checksum; set `CODECLEW_VERSION=v0.13.50` and
`CODECLEW_ASSET_DIR` to their directory.

The default profile includes Kotlin 2.4.10 and conditional Rust/Python mutation.
Rust/Python evidence retains PARTIAL/UNSURE status and requires native validation
and explicit acknowledgement of obligations. Documentation is retained source
interpretation, not runtime or deployment proof.
