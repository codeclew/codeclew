# Codeclew 0.14.7 — readable process steps and field contracts

Native process pages lead with a numbered explanation of all authored steps,
including branches, returns and deferred work. Sequence messages open their exact
operation-scoped step instead of opening source evidence. The selected step is
highlighted and focused; Back to diagram and Escape return to the originating
link. Source and declaration evidence remain separate explicit actions. Missing
authorship stays visibly unfinished with author repair guidance.

Known parse and syntax-authority limitations now explain their local impact.
Complete retained paths wrap on narrow screens; exact diagnostics remain in
secondary details. Unknown diagnostic codes remain literal, without guessed
interpretations. Original authored limitations are preserved.

New source-derived payload proposals require one explicit field path, direction
and independently evidenced description per row. Request, response, event and
record identities remain distinct. Historical grouped descriptions remain intact
in retained evidence with a targeted repair using the same Work sources, without
recapture or automatic reapproval. Structured declarations keep their own field
inventory and expose missing individual meanings. The process reader preflight
checks structural meaning and field-identity presence; semantic quality and
completeness still require native validation and reader review.

Broad documentation requests also default to human-oriented authored pages with a
checked local HTML preview. New repositories use supported registration/capture
before returning to that route; frozen roots reuse retained evidence. The packaged
Codeclew-shell renderer handles plain Markdown with pinned dependency setup and
checked finalization. Explicit MDX/Docusaurus, native Work/proposal and historical
rendering routes remain available. Runtime upgrade and installed skill refresh
are separate operations.

Completion guidance covers the requested purpose, processes, domain and individual
fields, scoped ingress contracts, outgoing calls/configuration, local failures and
crosslinks. Catalogues, GAP cards and successful mechanical checks do not complete
missing explanations. Canonical and agent discovery skill packages remain identical.
