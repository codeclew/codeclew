# Codeclew 0.14.7 — human-oriented documentation by default

Broad requests to generate or update service/process documentation now start with
authored human pages and a checked local HTML preview. Routing follows the
requested reader result: a new repository first uses supported registration and
capture, then returns to the same human-page route; an existing frozen root reuses
its retained evidence without recapture.

The default preview uses the packaged Codeclew-shell renderer for plain Markdown,
with explicit pinned dependency setup, trusted renderer arguments and checked
finalization. Explicit Docusaurus/MDX output retains its selected export route;
the Markdown finalizer does not execute native MDX/JSX components. Bounded SOURCE
Q&A, explicitly requested native Work/proposal/coordinator deliverables and
historical native rendering remain supported.

Completion guidance now checks the requested purpose, threads, domain and fields,
full scoped ingress contracts, egress and known destination configuration, local
failures and useful crosslinks in the actual reader pages. Catalogues, automatic
structure, GAP cards and successful render/binding checks do not complete missing
explanations. Source authority, genuine evidence limitations and independent
semantic/reader review remain separate from mechanical proof integrity.

The portable reader-checklist link resolves from the skill entry point, with
copy-based link regression checks. Canonical and agent discovery packages match.

Update the runtime with `clew upgrade`. Refresh the agent skill separately: for a
compatible agent's skills root, use `clew skill install --destination SKILLS_ROOT
--force`, or use the supported `--agent codex` / `--agent claude` destination.
Read the returned installation path and digest, then select that bundled SKILL.md.
Updating the runtime alone does not guarantee that a previously installed agent
skill is refreshed. Preserve an already-running task's admitted runtime until its
current run ends before switching versions.

This release changes generic instructions and package link checks. It does not
certify the completeness of any particular repository's generated documentation.
Source evidence and private documentation stay within the caller's authorized
local scope.

Packages support macOS Apple Silicon/Intel and Linux x86_64, including WSL2. Linux
requires glibc 2.35+ and Python 3.11+. The installer verifies published SHA-256
checksums and does not compile Codeclew locally.
