# Codeclew 0.15.5 — portable retained transformed source

Existing compiler snapshots containing `TRANSFORMED_SOURCE`, including retained
Lombok-expanded text, can be exported and imported without another capture or
compilation. The package preserves source text, digests, coordinates and authority;
transformed text keeps a null original-commit URL and cannot claim committed
`textOrigin` provenance.

```sh
clew upgrade
clew docs evidence export --root DOCS_ROOT --service SERVICE_ID --snapshot SAVED_SNAPSHOT --output NEW_PACKAGE_DIRECTORY
clew docs evidence inspect --input NEW_PACKAGE_DIRECTORY
```

Use the existing saved snapshot and a new output directory. Do not edit cached
source records, relabel their authority or add original-source links to work
around a prior refusal. Changing current source-web settings does not rewrite
frozen transformed evidence.

The existing compiler-context admission also supports a correctly bound compiler
library inside a SOURCE consumer. The library keeps its own provenance; the
consumer does not gain compiler resolution or runtime proof. Ordinary SOURCE
without an admitted compiler-library binding remains outside this allowance.

Portable formats 1.0/1.1, finite size limits, source/reference integrity, trusted
manifest expectations and failed-import publication protection remain enforced.
Historical imports remain historical and NON_CACHEABLE. Package integrity alone
does not establish source authenticity or source-to-binary equivalence.
