# Codeclew 0.15.0 — guided documentation and connected processes

The bundled skill guides full documentation requests from retained evidence to
reviewed human pages, with clear stage outputs, recovery commands at the point
of use and an author check against the original request before completion.
Native Work/proposal and bounded SOURCE Q&A remain explicit routes. Checked
rendering establishes bindings and links; reader-level meaning and completeness
still require review.

An optional cross-docset registry connects independently authored service guides,
shared process narratives and a common catalogue. Services link to their starts
and process participation; shared processes link back to each service and the
catalogue. A portal or shared narrative needs no fabricated application service.
Evidence roots, documentation ownership and hosting namespaces stay distinct.

Catalogue filters find processes by their start, terminal operation owner,
internal service and outcome. Repeated roles in one service remain distinct.
Selections within a filter use OR; filters combine within one compatible
outcome. Partial and unclassified cases remain visible by default. Terminal
owners are separate from response recipients, and known starts remain searchable
before outcomes have been classified. Keyboard controls, collapsed narrow-screen
filters and expandable outcome details keep the reading path compact.

Local pages, unique anchors, service ownership and declared current docset
versions are checked. HTML records the exact registry digest. Remote destinations
remain declared and are not fetched; an attributed report of a missing, renamed
or version-drifted destination retains the process with that link disabled.
This navigation does not verify deployed versions or add source authority.

Documentation diagnostics distinguish malformed authored declarations, missing
root manifests, unsupported schemas and damaged or unselected object storage.
Process errors identify the affected record and field. Conflict responses expose
the current input digest when it can be computed, so authors can inspect and
reconcile changes. External, interaction and process put commands accept bounded
stdin via `--input -`; write-conflict and input-size protections remain in force.
Frozen export guidance now names supported selectors, recovery actions and input
formats more directly.

This release retains the existing imported-library citation-helper and external
human-claim binding limitations. Cross-docset navigation does not repair those
bindings. Supported public pilot packages remain macOS Apple Silicon, macOS Intel
and Linux x86_64, including WSL2; existing C# Roslyn support remains included.
