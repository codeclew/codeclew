Codeclew 0.13.44 stores new documentation bindings as bounded service, subject
and shared partitions. Immutable portable objects share unchanged evidence across
publication generations. Exact source occurrences, historical fragments, review
state and uncertainty remain attached to their original records.

Inline bindings 1.4/1.5 remain readable. New writes use schema 1.6 and require an
upgraded reader. Preserve the selected generated bundle, pointer and every object
in its declared `docs/evidence/objects/` closure. The paginated
`docs history show --kind bindings-closure` command lists that closure. Commands
reject missing, corrupt, conflicting, unsafe or over-budget objects before
switching the publication pointer; immutable objects are never silently repaired.

Complete cold publication copies support read-only history and unprotected
baseline inspection without a private SQLite database. Original `.codeclew/`
Work and protected source snapshots remain separate authoring backup requirements.
Site generation still needs its explicitly selected saved snapshot and protected
contexts. Existing reading exports can be copied as complete directories.

Embedded standalone and Docusaurus exports include their complete portable
closure. Remote exports project selected source records before creating a fresh
reading-only closure, so unused source text in reused storage chunks cannot leak
through auxiliary downloads. Authored quotations, contracts, provenance and exact
historical links remain; remote bindings cannot be reimported as evidence.

The 128 MiB bindings and 64 MiB cumulative Full Pages limits remain. The first
storage slice still hydrates selected bindings eagerly; it makes no bounded-memory
or command-latency claim. The fixed synthetic three-publication fixture reduced
total stored bytes, including metadata, by 7%, 38% and 58% for 1, 10 and 100
services respectively. These development-profile measurements are not customer
workload guarantees. The first publication costs about 2%, 7% and 12% more than
inline storage at those sizes; savings appear across retained generations.
See the portable-bindings operational guide for copy,
restore, compatibility and export requirements.
