# Codeclew 0.6.1 — bounded documentation diagrams

Documentation diagrams now use a separate, authored business overview with at
most 12 nodes and 20 connections. A full compiler traversal remains available
as structured evidence and source commentary; it no longer becomes a diagram
with hundreds of low-level steps. HTML, Markdown and Mermaid share the same
bounded overview.

Each node and connection retains source-event references and participates in
freshness checks. Cross-service connections must retain the matching declared
transition. Validation rejects oversized diagrams, overlapping grid positions,
missing evidence and unsupported service connections. Existing narratives remain
readable; new schema 1.3 requires a bounded diagram.

The portable skill now asks authors to show triggers, meaningful decisions,
actions and outcomes in 4–9 nodes, split larger scenarios and review the rendered
diagram at a normal desktop size. Interface contracts and source commentary are
preserved independently of the visual summary.

The static diagram is an authored interpretation, not a runtime trace or a
proof of broker delivery. Supported language and mutation profiles are unchanged
from 0.6.0.

Install the published package:

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.6.1 sh
clew skill install --agent codex
```
