# Codeclew v0.13.4 — native source documentation pages

## Linked pages from retained Java source

`docs pages render` produces process overview, selected endpoint, worker,
field/state and diagnostic pages in standalone HTML and inert MDX 3. One typed
projection supplies both formats, a shared source appendix, relative navigation
and a manifest of content hashes. HTML needs no JavaScript or network dependency.

The input selects exact callable declarations from an explicit immutable
documentation snapshot. Conditions, source expressions, call targets and local
uncertainty come from retained evidence; no pre-authored answer or DSL effect
labels are required. Rendering performs no source capture or latest-pointer
fallback and refuses existing output files.

## Source semantics and provenance

- Supported Java statement paths preserve branch polarity, early returns,
  source order, defaults, transformations and local state expressions.
  Unsupported constructs and unresolved continuation paths remain explicit gaps.
- Shared queue wiring requires a concrete local allocation, exact compiler
  construction relations and direct constructor-to-field bindings. Similar
  names or types, ambiguous constructions and reassigned parameters establish
  no shared-object proof.
- External calls retain DEP-01 target and source-availability metadata.
  Available dependency source uses its retained local citation; a missing
  original URL never becomes a fabricated repository link.

Offer success, worker activation, concrete runtime dispatch, external success,
business delivery and actual incident causes require additional evidence. A
selected callable does not itself establish an HTTP route. This is a bounded
Java source projection, not automatic discovery of every business process.

## Reading and updating

Overview pages lead with the source conclusion or local uncertainty. Exact
identities and version details remain accessible through native disclosures;
diagnostic and field tables retain readable columns with keyboard-accessible
horizontal scrolling. Source links resolve within a moved static bundle.

Capture a new snapshot after changing source and export to a new directory.
Older snapshots still render from retained evidence after the checkout or
latest pointer becomes unavailable. Protected authored-content editing and
live grounded Q&A are subsequent programme increments.

See the [native pages guide](https://github.com/codeclew/codeclew/blob/v0.13.4/docs/guides/native-static-pages.md).

## Public pilot scope

The package matrix remains macOS arm64 and x86_64, and Linux x86_64 including
WSL2. Native Windows, Linux ARM64 and musl remain outside the matrix. The
default core profile contains Kotlin 2.4.10; the optional kotlin23 profile adds
the Kotlin 2.3.0 read-only preview. Signing, notarization, actual corporate
capture and human usability qualification remain outside this selected slice.

Install the published pinned version:

```bash
curl -fsSL https://codeclew.github.io/codeclew/install.sh | CODECLEW_VERSION=v0.13.4 sh
```
