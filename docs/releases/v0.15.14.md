# Codeclew 0.15.14

Native FIR capture can now build its observer against the FIR API used by
Kotlin 2.2.21. On Gradle 8.14.1 with JDK 21, the selected Kotlin compilation
can capture exact links to kapt-generated Java and to methods opened by the
Spring preset and an explicit all-open annotation.

The Kotlin 2.4.21 regression uses Gradle 9.4.1 and a JDK 25 toolchain and
target. It checks kapt and a separate Java generator scheduled by
`compileJava`, both all-open option forms, exact source spans, and the input
and classfile hashes from a separate native build.

When the observer cannot be built, Codeclew can report the failed stage and
a bounded reason separately from the analyzer's ABI decision. The shareable
support report omits compiler logs, file paths, and raw plugin arguments
from this diagnostic.

See [Gradle capture settings](https://github.com/codeclew/codeclew/blob/v0.15.14/docs/operations/gradle-project-properties.md)
for selected compilations, project properties and local Git tags.
Codeclew remains a public pilot for macOS and Linux. Upgrade with
`clew upgrade` or use the [installation guide](https://codeclew.github.io/codeclew/).
