# Codeclew 0.13.52 — readable retained documentation

Codeclew can render the same saved documentation as the historical reader or
sequential MDX, with readable service summaries and field tables, direct contract
destinations, compatible operation anchors and complete original provenance.

OpenAPI documents expose declared methods, paths, parameters, requests and
response fields. JSON Schema composition branches keep their separate conditions.
Exact source and original schema stay available; this reader does not validate
runtime conformance or resolve schema references.

Retained snapshot recovery selects exact original service captures. Full syntax
file claims and complete service bodies can be admitted without recapturing
source. Presentation plans can contain contracts without inventing domain models.

Public pilot for macOS Apple Silicon/Intel and Linux x86_64, including Windows
through WSL2. Linux requires glibc 2.35+ and Python 3.11+. On Windows, keep the
installation, state and repositories in the WSL2 Linux filesystem.

```sh
curl -fsSL https://codeclew.github.io/codeclew/install.sh | sh
```

The installer verifies published SHA-256 checksums and never compiles Codeclew.
The core package includes Kotlin 2.4.10 and C# Roslyn. Conditional Rust/Python
mutation remains a public pilot with PARTIAL/UNSURE evidence, native validation
and explicit obligation acknowledgement. Apple code signing and notarization,
native Windows, Linux ARM64 and musl distribution remain outside this release.
