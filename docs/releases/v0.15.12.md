# Codeclew 0.15.12

Kotlin Gradle compiler capture can now expose existing local Git tags inside
its isolated checkout. Enable `gradle.gitTags: true` in the bound checkout's
local `codeclew.yaml` when the build reads tags during configuration.

Capture preserves lightweight and annotated tag identities and includes
competing tags in Git version sorting. The build still controls which tags
it accepts. Changes to the admitted tag set invalidate live capture reuse
even when the source commit stays the same. The setting is opt-in.

See [Gradle capture configuration](../operations/gradle-project-properties.md#supply-local-git-tags-to-kotlin-gradle-capture)
for the supported queries and limits.

Codeclew remains a public pilot. Upgrade with `clew upgrade`.
