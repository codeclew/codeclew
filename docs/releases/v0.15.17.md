# Codeclew 0.15.17

`clew docs check --working-tree` now captures tracked symbolic links with
direct relative targets inside the captured checkout. The staged link text
and saved link text are retained separately. Changing a saved target changes
the source snapshot digest at the same Git commit.

The isolated compiler build uses only the captured inputs. Absolute,
escaping, chained, untracked and dangling links remain outside the
supported working-tree capture. See the
[Gradle capture guide](https://github.com/codeclew/codeclew/blob/v0.15.17/docs/operations/gradle-project-properties.md).
