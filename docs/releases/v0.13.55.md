# Codeclew 0.13.55 — macOS and Linux public pilot

The documentation reader now makes it easier to move between a process, its
fields, external participants, payload shapes and retained source evidence.

HTTP operations show one method/route identity and provide exact-path copy
feedback. Standard and editorial search recover visibly from no matches; page
and tab titles follow section navigation, direct links and browser history.
Sequential reading retains its deliberate absence of local navigation search.

Canonical field inspection keeps each field's own representations and uses
separate, including fields with identical readable names. Returning restores
focus to the original field row. Missing or ambiguous evidence remains visible.

External-profile contents include the retained request, response and message
shapes. Boundary cards link through explicit operation and interaction identities.
Short position headings stay intact while long code expressions wrap.

Sequence diagrams can be expanded in place without cloning their SVG or source
controls. Horizontal and vertical panning keep text readable. Escape closes an
open source panel first, then returns from expanded reading to the original
process position and action. Reopening retains the diagram's reading position.

Five independently accepted polish cycles cover these interactions. Original
prose, source bindings and the distinction between compiler, SOURCE, declared
and runtime authority are preserved. Static documentation does not establish
runtime execution or message delivery.

The distribution remains a public pilot for macOS Apple Silicon/Intel and Linux
x86_64, including Windows through WSL2.
