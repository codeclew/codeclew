# Codeclew 0.15.8 — retained reads and author usage

Concurrent documentation reads now wait for the short receipt write, reload the
saved state and preserve each other's receipts. Ordinary competing mutations
still fail immediately with `WW_CONFLICT`.

Documentation runs count cumulative author usage once per thread and record each
resumed attempt's delta alongside its original report. Missing or ambiguous
identity, changed resume identity and invalid counters prevent readiness instead
of producing an exact within-budget claim. The existing whole-document author and
same-thread repair process remain the public default.

The read-only `review-template` command validates frozen inputs without running
native commands or writing receipts. Verification and promotion still check the
admitted runtime version and Markdown parser.

SOURCE membership checks use bounded navigation metadata while retaining full-body
citation proof and owner, snapshot, revision, digest and range checks. Failures
include bounded native and transport causes without copying source bodies or logs.
Compiler-backed evidence keeps its existing context route.

These are independent technical fixes. They do not establish lower authoring cost
or successful complete Weather documentation.
