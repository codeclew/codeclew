01 · AuthorityReleased contract

Admit the exact task authority

Codeclew starts from one installed release, repository, target ref, language and compilation instead of inferring a convenient project boundary.

Mechanism

The admission result must report RELEASE runtime authority, the installed launcher and no source fallback.

clew context open --repo … --target-ref … --language … --compilation …

Bound fact

Require runtimeMode=RELEASE, launcherAuthority=INSTALLED_RELEASE, and sourceFallbackAllowed=false.

This proves the released task-admission contract. It does not prove that every repository is supported or that a later analysis is complete.

Why this format matters

Documentation remains useful when confidence is local.

A reader can inspect each statement independently. A released contract, a syntax observation, a compiler fact and an unresolved obligation do not inherit one another's confidence merely because they appear in the same graph.
