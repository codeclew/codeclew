Three changes, three decisions

Public Pricing fixture · installed release 0.13.11 · main and explicit test scope

This case compares HEAD with saved files. price() returns 1 at HEAD, 2 in the index and 3 in the saved file. The report uses the saved 3. It also changes label(Int) to label(Long) and removes a call from stopCalling().

1. The price body changed

consumer() is unchanged but calls Pricing.price(). Inspect its retained before/after source and decide which expected price values need a test.

Next check: review the expectations in PriceTest.kt and run the relevant project tests separately.

2. The label parameter changed

The signature moves from Int to Long. Inspect labelConsumer() and other returned direct candidates before deciding whether their call arguments still fit.

Next check: compile the changed scope and inspect callers outside the selected scope.

3. A call disappeared

stopCalling() previously called Pricing.price(); the saved body returns 0. The before-call evidence survives. Under partial after coverage, an unresolved relation is not proof that no call remains anywhere.

Next check: read the saved body and assess the missing coverage before concluding the effect is gone.

The main-only run does not analyze tests. The explicit :/main + :/test run retains a compiler-resolved PriceTest.priceCheck → Pricing.price call in both snapshots. The unchanged test expects 1 while the saved function returns 3: a concrete check to run. Clew inspection does not execute it or prove that it fails. Coverage remains partial, with 30 unresolved relations and 16 nodes omitted from the bounded graph response.

Prepare the public Pricing fixture

Use a caller-owned source checkout and a new fixture directory. The setup script copies the public Kotlin build fixture, creates a base commit, stages the intermediate price, then writes the three changes above plus the original added/deleted/renamed file cases. It makes no Clew or model calls. It refuses to replace an existing destination.

git clone --branch v0.13.11 https://github.com/codeclew/codeclew.git codeclew-example
curl -fsSL https://codeclew.github.io/codeclew/examples/saved-edits-fixture/setup.py -o pricing-setup.py
python3 pricing-setup.py \
  --checkout ./codeclew-example --output ./pricing-example
fixture="$PWD/pricing-example"
clew doctor repository --repo "$fixture" --working-tree --human

Download setup.py. Kotlin compiler inspection needs JDK 21 and the project's Gradle wrapper. The recorded fixture uses Kotlin 2.4.10 and profile kotlin-2.4.10-gradle-single, with compilations :/main and :/test. Use the ready scope returned for your checkout; main alone does not include tests.

Inspect the saved files and render a report

clew change inspect --repo "$fixture" --target-ref main \
  --language kotlin --profile DISCOVERED_PROFILE \
  --compilation DISCOVERED_COMPILATION --working-tree --base HEAD
clew change graph --comparison RETURNED_COMPARISON
clew change render --comparison RETURNED_COMPARISON \
  --output ./saved-edits-report.html
clew change source --comparison RETURNED_COMPARISON \
  --node RETURNED_NODE --side after

Use the profile and compilation returned by discovery, then the comparison and node identities from inspection. Open saved-edits-report.html, select a changed declaration or direct connection, and read its exact source. Add test compilations explicitly when you need their relations.

Check freshness after another saved edit

clew change check-freshness --comparison RETURNED_COMPARISON
# Save another change in the fixture, then repeat:
clew change check-freshness --comparison RETURNED_COMPARISON

A retained comparison still describes its saved evidence after the checkout changes. An observed LIVE_CHANGED result tells you to create a new comparison when current edits matter. It does not corrupt the old source or update the report automatically.

After inspection, the recorded case changes only saved stable() = 9 to 10. Freshness returns LIVE_CHANGED, liveSnapshotMatches: false and retainedEvidenceValid: true. Reading the old comparison still returns stable() = 9 and price() = 3, byte-identical to its original retained source. HEAD, index and refs remain unchanged.

Run the project checks you selected

Use the report to choose what to inspect and test. Run the fixture's relevant compilation and tests explicitly; Clew inspection does not execute them. Compiler failures, unresolved targets and omitted scopes remain limits even when a retained report opens correctly.

A separate earlier caller-project check ran ./gradlew --no-daemon check on this fixture: main and test compilation succeeded, and one test failed with expected 1, actual 3. Clew did not run that check, and the installed case did not repeat it. The compiler call identifies a verification candidate; the separate test execution supplies the observed failure.
