Path to strict validation later

Pre-register the gate, then freeze the receipts.

  1. Held-out tasks. Select engineering tasks before inspecting outcomes.
  2. Balanced order. Counterbalance Codeclew-first and default-first runs.
  3. Symmetric warm state. Give both arms equivalent caches and preparation.
  4. Equal execution. Use the same model, runner, prompt budget, and stopping rule.
  5. Frozen evidence. Retain raw hashes, runtime identity, revisions, outputs, and costs.
  6. Blinded oracle. Score correctness without knowing which arm produced the answer.
