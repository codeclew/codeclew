Experimental release result · v0.13.1

One source-local Java method draft.

The public fixture selects TaskStateTransitions.promote(Task, Instant) in the Maven :/main compilation. It explains the method's local decision and repository-call boundaries. Its authored decision tree is rendered as pseudocode; the separate flow SVG is projected from retained source syntax, not from authored steps.

The saved provenance records one author call (164.078 seconds) and a replay of the same saved result with no new author dispatch. A separate source-FIT review and browser review accepted this scenario; the native result remains DRAFT / UNREVIEWED, with publication NOT_PUBLISHED.

This evidence covers one method and its rendered sample. It does not establish runtime activation or execution, runtime execution order, later dispatch, external effects, persistence, deployed behavior or complete-workflow qualification. The single-run timing is diagnostic, not a latency promise.
