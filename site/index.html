The everyday analysis flow

Discover. Catalogue.
Inspect. Document.

Install Codeclew and its skill, then ask your agent to explain a service. It carries the returned scope and evidence through each step.

01

Discover the build

Identify the project, supported profile and exact compilation. Choose committed analysis when local edits should stay outside the snapshot.

clew doctor repository …
02

Catalogue the roots

Open analysis context, then enumerate Spring triggers across the selected sessions. Follow every page and retain coverage boundaries.

clew entrypoints …
03

Inspect exact source

Use each returned callable identity to inspect its declaration and supported relations. Overloads keep distinct identities.

clew nav expand … --file … --source
04

Write the explanation

The agent describes each thread, cites the retained source and names unresolved configuration or integration steps.
