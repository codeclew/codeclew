# Standard service sections

`docsys_t08_required_sections_small_and_forty_boundary_services_with_local_failure`
creates two isolated committed Java 17 source repositories: a small callable
service and a Spring controller with forty distinct long HTTP routes. Both use
the source provider with no compiler or model executable on PATH.

The fixture checks mandatory sections, public/internal inventory separation,
source references, local authoring failure and Markdown structure. Set
`CODECLEW_DOCSYS_T08_REVIEW` to a temporary directory to retain both standalone
HTML pages for desktop/mobile inspection.

The entity regression declares a human owner and a separate proposed candidate,
then changes a linked entity to check transitive document invalidation. Duplicate
titles do not merge identities; title changes do not rebind references. The macOS
section work test uses the existing isolated deterministic author/reviewer
transport fixture; it does not measure real model writing quality.
