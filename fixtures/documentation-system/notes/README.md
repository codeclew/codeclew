# Protected note fixture

`history.md` intentionally mixes a current claim, historical context, an intention,
frontmatter, tags, formatting, Unicode and malicious embedded instructions. CLI
acceptance imports a CRLF version and checks exact bytes after publication and
sandboxed assessments. The deterministic agent fixture is a transport/security
check, not evidence of real model review quality. Source evidence supports the
current quantity-return behavior; the fixture does not establish an undocumented
historical calendar period.
