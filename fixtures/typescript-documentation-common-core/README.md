# TypeScript documentation common-core probe

Public synthetic TypeScript 5.9.3 project. Run `npm ci` before selecting
`tsconfig:tsconfig.json` with `typescript-5-project-read-only`.

`render` retains typed input/return declarations, guards, locals and exact
ordinary helper navigation. Interface dispatch and external string methods
remain frontiers. `opaque`, `ambiguous` and `loop` exercise any/optional-call,
overload and unsupported control boundaries. `Probe.ts` deliberately contains
a UTF-8 BOM, CRLF, Unicode and inert markup.
