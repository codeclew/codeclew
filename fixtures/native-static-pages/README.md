# Native static page fixtures

These two ordinary Java source scenarios contain no authored operation answers,
flow DSL annotations or effect labels. The integration test compiles a local
`external.Gateway` dependency and captures each checkout through the native
Maven/javac documentation producer. The tiny Maven wrapper supplies compiler
acquisition metadata only; it does not establish a corporate build outcome.

Alpha has one explicit queue allocation and constructor wiring. Beta uses
renamed symbols, missing-settings local state, a fallback value and ambiguous
endpoint construction. Its gateway dependency has binary metadata only.
Neither scenario establishes offer success, runtime worker activation, business
delivery or an external implementation's internal behavior.
