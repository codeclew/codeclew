# Review and repair authored documentation

Compare the draft with the full user question and its retained source evidence.
Check entries, sequence, conditions, contracts, side effects and failures. Keep
unknown behavior explicit. Review helper bodies and data shapes when available;
do not turn a navigation lead into a claim that evidence is missing.

Correct the original text, then use the existing [guarded human-page update](compose-original.md#original-pages-and-completion).
Preserve unchanged fragments, provenance and source bindings. An export check
verifies mechanical bindings and output integrity; it does not approve meaning.
If the user requests independent review, keep that review and its findings
separate from source authority. No native proposal assembly or publication route
is required.
