# Repair evidence-bound documentation

Preserve the original question, authored text, exact source manifests and previous
index. Follow missing source references before treating a claim as unsupported.
Correct the original or its explicit citations and use the existing
[guarded human-page update](compose-original.md#original-pages-and-completion).
Do not fabricate evidence, replace source authority or recapture merely to pass
an export check. Keep unresolved behavior visible beside the affected step.
